* **Зектер Софія 1 (Тімлід / DevOps):** Налаштування репозиторія, архітектура, `app.py`, `base.html`, `index.html`.
* **Шабат Анна 2 (Backend & Content):** Маршрути та сторінки «Про нас» (`about.html`) і «Послуги» (`services.html`).
* **Косухіна Олександра 3 (Frontend & UI/UX):** Маршрути, сторінка «Контакти» (`contact.html`) та адаптивність верстки.
* **Головачук Дарина 4 (QA & Documentation):** Тестування, контроль якості, GitHub Issues, файл `README.md` та координація звітів.
