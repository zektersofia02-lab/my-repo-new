## 2. Виконані завдання (Моя частина)

У межах командного проєкту я відповідала за перевірку вхідних запитів та обробку виняткових ситуацій (помилок). 

1. **Валідація вхідних даних:**
   - Перевірка наявності обов'язкових полів (`title`, `price`, `product_id`) при створенні та оновленні сутностей.
   - Перевірка типів даних (числові та текстові обмеження).
   
2. **Обробка неіснуючих ресурсів (404 Not Found):**
   - Усі маршрути (`GET`, `PUT`, `PATCH`, `DELETE`) для товарів (`/products`) та замовлень (`/orders`) перевіряють наявність запису в базі даних SQLite за його ID. Якщо запис відсутній, сервер повертає статус `404` із відповідним JSON-повідомленням (`{"error": "..."}`).

3. **Формат відповідей:**
   - Усі помилки та успішні результати повертаються у форматі JSON за допомогою функції `jsonify()`.

## 3. Приклади коду та реалізації

### Приклад обробки помилок та валідації у `routes/v1.py`:
```python
@api_v1.route("/products/<int:product_id>", methods=["GET"])
def get_product_v1(product_id):
    row = get_db().execute(
        "SELECT * FROM products WHERE id = ?", (product_id,)
    ).fetchone()
    if row is None:
        return jsonify({"error": "Послугу/товар не знайдено"}), 404
    return jsonify(dict(row)), 200
