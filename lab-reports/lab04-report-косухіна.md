
# Звіт до лабораторної роботи

**Роль у проєкті:** Учасник 3 — Розробник адмін-панелі та додаткової таблиці

**Виконавиця:** [Косухіної Олександри]

---

### 1. Мета роботи

Розширення функціоналу вебзастосунку на Flask, проєктування додаткової реляційної таблиці в базі даних SQLite та розробка зручної панелі адміністратора для управління категоріями послуг/товарів.

### 2. Виконані завдання та внесок у проєкт

* **Проєктування бази даних (`models.py`):**
Створено додаткову таблицю `categories` для Рівня 2 з полями `id`, `name` (назва категорії, унікальна) та `description` (опис). Інтегровано її в загальну систему ініціалізації бази даних проєкту.
* **Розробка логіки адмін-панелі (`routes/admin.py`):**
Створено окремий модуль (Blueprint `admin_bp`), що відповідає за обробку запитів адміністратора. Реалізовано функціонал перегляду існуючих категорій та додавання нових через POST-запити.
* **Створення інтерфейсу (`templates/admin/categories.html`):**
Розроблено адаптивний HTML-шаблон для управління категоріями в єдиному бірюзовому стилі проєкту (з використанням Tailwind CSS), який містить форму для введення даних та таблицю зі списком категорій.
* **Інтеграція у застосунок (`app.py`):**
Зареєстровано блюпринт адмін-панелі в головному файлі Flask-застосунку (`app.register_blueprint(admin_bp)`), що забезпечило доступ до сторінки за маршрутом `/admin/categories`.

### 3. Тестування та результати

* Проведено локальне тестування адмін-панелі через браузер (`[http://127.0.0.1:5000/admin/categories](http://127.0.0.1:5000/admin/categories)`).
* Перевірено успішне збереження нових категорій у базі даних `db.sqlite` та їх коректне відображення в таблиці на сторінці.
