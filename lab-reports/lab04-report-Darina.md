# Індивідуальний звіт з лабораторної роботи №3

**Виконала:** Головачук Дарина  
**Роль у команді:** QA & Documentation Engineer    

---

### 1. Мета роботи
Реалізувати та протестувати функціонал форми зворотного зв'язку на вебсайті, налаштувати збереження відгуків користувачів у реляційну базу даних SQLite та оновити проєктну документацію.

### 2. Виконані завдання
1. **Верстка інтерфейсу (`templates/contact.html`):**
   * Створено та стилізовано за допомогою Tailwind CSS форму зворотного зв'язку з полями для введення імені (`name`), електронної пошти (`email`) та тексту повідомлення (`message`).
2. **Оновлення структури бази даних (`models.py`):**
   * Модифіковано SQL-схему таблиці `feedback` у функції `init_db()` — додано обов'язкове поле `email TEXT NOT NULL` для збереження контактної пошти користувача.
   * Перестворено локальний файл бази даних `db.sqlite` для застосування оновленої схеми.
3. **Серверна логіка (`app.py`):**
   * Оновлено маршрут `/contact` із підтримкою методів `GET` та `POST`.
   * Реалізовано зчитування даних із форми (`request.form.get`), виконання параметризованого SQL-запиту `INSERT INTO feedback` та перенаправлення (`redirect`) після успішного збереження.
4. **Тестування та контроль якості (QA):**
   * Проведено ручне функціональне тестування відправки форми з валідними даними.
   * Перевірено коректність запису даних у таблицю `feedback` бази даних SQLite.

### 3. Результати та труднощі
Робота виконана в повному обсязі. У процесі реалізації, тестування та інтеграції модуля зворотного зв'язку **жодних труднощів не виникло** — усі компоненти працюють стабільно та без помилок.

### 4. Висновки
Під час виконання лабораторної роботи було закріплено навички обробки `POST`-запитів у фреймворку Flask, роботи з базою даних SQLite, тестування клієнт-серверної взаємодії та командної розробки з використанням системи контролю версій Git та GitHub.
